WINDOWS HOME SETUP

Your desktop inside /vm

This displays and controls your home PC directly on quota.wamomath.org/vm. It uses a locally served noVNC viewer and your Render server as the relay. There is no external viewer, Google account, iframe, or Cloudflare configuration.

Software on the home computer must share its desktop. Arrange administrator help if the installers request it. These website changes do not install anything on Windows.

1. Configure desktop sharing at home

  1. Install the Server component from TightVNC's official site. Use service mode for access after reboot.
  2. Set a VNC password and an administration password. Under Access Control, allow loopback connections and select only loopback connections. Use port 5900.
  3. Disable the legacy HTTP/Java viewer. Do not add router port forwarding or public firewall exceptions. Configure lock desktop when the last client disconnects.
  4. Test locally at 127.0.0.1:5900. Keep the PC awake and online.

The vendor reference documents these options. Chrome Remote Desktop software is not used.

2. Prepare the home connector

  1. Install Node.js LTS on the home PC.
  2. Download the connector ZIP, extract it to a private folder, and open a terminal in the folder containing package.json.
  3. Run:
npm ci
node configure.mjs

This creates private config.local.json and render-settings.local.txt files with separate random credentials. It transmits nothing and will not overwrite existing settings.

3. Configure and deploy Render

Copy the values from render-settings.local.txt into your existing Render web service's Environment settings:

VariablePurpose
VM_PUBLIC_ORIGINhttps://quota.wamomath.org
VM_ACCESS_PASSWORDThe generated website sign-in password.
VM_AGENT_TOKENThe connector secret matching config.local.json.
VM_ENABLEDtrue
VM_COMPUTER_NAMEYour friendly computer name.

Deploy these repository changes using npm run build and npm start. Use one Render instance so both connections reach the same relay. Keep existing database/JWT settings. Remove obsolete VM_GATEWAY_URL; Supabase needs no changes.

Keep both generated files private. Do not upload, commit, or send them in chat. Keep the website password in your password manager. The VNC password is separate.

4. Start the home connector

npm start

Wait for Home connector online and leave the terminal running. Ctrl+C stops it. It reconnects after temporary interruptions; run it again after restarting the PC.

5. Connect from school

  1. Visit https://quota.wamomath.org/vm and enter the generated website password.
  2. When the connector is online, select Connect to home desktop.
  3. Enter the home VNC password. The desktop appears on this page. Click it for keyboard and mouse control.
  4. Use fullscreen, Ctrl+Alt+Del, view-only, or text paste in the toolbar. Lock Windows, disconnect, and sign out when finished.

Limits and troubleshooting

One PC and one viewer at a time. Website sessions expire after 30 minutes. Ten login attempts within ten minutes trigger a temporary lockout. Server restarts close sessions; reconnect after the home connector returns. Audio and file transfer are not implemented. Video uses Render bandwidth.

StateCheck
Setup requiredSet all Render variables and redeploy. Password: at least 16 characters; token: at least 32; they must differ.
Sign-in failsUse the website password, not VNC's. VM_PUBLIC_ORIGIN must exactly match your website origin.
Home offlineKeep the PC awake and connector running. Check its token matches Render.
Desktop connection failsCheck local VNC, its password, and the connector terminal.
409 or already connectedClose duplicate connectors or viewers.
Intermittent on RenderUse one instance; pairing is held in memory.
Blocked at schoolAsk school IT whether remote access is permitted.

Internet traffic uses TLS to Render. Render is a trusted relay, so this is not end-to-end encryption against the server operator. Do not run untrusted code in the site's compiler during privileged sessions. Network and device restrictions still apply.

Disable access

Stop the home connector with Ctrl+C. Set VM_ENABLED=false and redeploy to disable the server feature. Rotate exposed secrets and update home configuration. Stop or uninstall TightVNC when no longer needed.

References: noVNC, Render WebSockets, and the locally served noVNC license.
