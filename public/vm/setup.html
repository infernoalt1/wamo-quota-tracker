CHROME REMOTE DESKTOP

Your home PC, in your browser

For your Windows 11 home computer and quota.wamomath.org on Render. No Cloudflare access, DNS changes, VNC server, or Supabase changes are needed. This controls your existing home desktop; it does not create a virtual machine.

1. At home

  1. Open Chrome and visit Chrome Remote Desktop. Sign in with your personal Google account.
  2. Choose Set up remote access and install the host software as prompted. If Windows asks for administrator approval, ask the computer's administrator to help.
  3. Finish enrollment, name the computer, and set its access PIN. Use Remote Access for your own computer, rather than a temporary support code.
  4. Keep the PC powered on, online, and awake. Test the connection from a second device before leaving home.

Google's official installation and connection instructions. Enter account credentials and the PIN only in Google's interface, never on WAMO.

2. Deploy the website changes

Deploy the updated repository to the existing Render web service using its normal build/start commands. The launcher now defaults to Chrome Remote Desktop without extra configuration.

If you already added the earlier Cloudflare gateway address to Render, replace it with the value below in the service's Environment settings. Otherwise these variables are optional:

VM_GATEWAY_URL=https://remotedesktop.google.com/access/
VM_COMPUTER_NAME=My home computer
VM_ENABLED=true

Save and deploy the environment changes. Keep the existing database and JWT settings. The backend's /api/vm/config supplies the launch address at runtime. In local development, Vite reads the same settings from .env.

3. From school

Open https://quota.wamomath.org/vm, select Open Chrome Remote Desktop, sign in to the same Google account, choose your PC, and enter its PIN. The session opens in Google's tab. Disconnect and sign out when finished on a shared computer.

Use remote access only where permitted. Managed devices or accounts can restrict this service; ask school IT if it is blocked.

What the launcher does

WAMO provides the entry point and instructions. Google handles host enrollment, authentication, device availability, and the remote session. The launch button being available does not mean your PC is enrolled or online. Visitors can only see computers authorized for their own Google account.

WAMO does not store your Google password or remote-access PIN. It does not embed or proxy the desktop, and it does not install host software when someone opens this page.

Troubleshooting

ProblemNext step
Old Cloudflare address opensReplace VM_GATEWAY_URL in Render with the Google address above and redeploy.
Setup unavailableConfirm that the Node backend serves JSON at /api/vm/config, rather than an HTML fallback.
PC missing or offlineCheck the selected Google account and finish host setup on the home PC. Check its power, sleep, internet, and host-service state.
Administrator promptAsk the home computer's administrator to approve installation. Website code cannot approve Windows elevation.
Service blocked at schoolAsk school IT whether it is allowed. The launcher does not override restrictions.

Disable access

Remove or disable your computer in Chrome Remote Desktop. To remove only WAMO's launch button, set VM_ENABLED=false in Render and redeploy; that alone does not revoke access at Google.
